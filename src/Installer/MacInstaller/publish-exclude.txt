# publish-exclude.txt
#
# Files and directories to leave OUT of the macOS app bundle.
#
# This is passed to rsync as --exclude-from when copying the dotnet publish
# output into the bundle staging directory, so it uses rsync's filter syntax:
#
#   Foo.dll             matches Foo.dll at any depth
#   /Foo.dll            matches Foo.dll only at the top level of the publish dir
#   *.pdb               glob, matches at any depth
#   sv/                 trailing slash matches directories only
#   **/Bar              ** crosses directory boundaries
#
# Blank lines and lines starting with # are ignored.
#
# Anything excluded here is simply absent from the .app -- there is no error if
# the app later tries to load it, so re-test the built app after each change.
#
# ---------------------------------------------------------------------------
# Candidates worth trying (uncomment to enable).
#
# Measured against the 4.0.0.110 build: the bundle is 533 MB, of which 399 MB
# is the runtimes/ tree described below.
#
# --- runtimes/ for other platforms: ~399 MB -------------------------------
#
#   AvPurplePen.csproj used to copy PdfConverter's entire build output into
#   the publish directory, including its RID-agnostic runtimes/ folder of
#   native pdfium and libSkiaSharp binaries for every platform (about 399 MB of
#   the 533 MB bundle measured against 4.0.0.110). PdfConverter is now a plain
#   library, and the self-contained osx-arm64 publish flattens the native
#   libraries it actually needs (libSkiaSharp.dylib, libpdfium.dylib and
#   friends) into the top level of the bundle, so the tree should no longer
#   appear at all.
#
#   Nothing would load it if it did: PurplePen.deps.json contains no
#   runtimeTargets entry, so nothing ever probes runtimes/. The exclusion stays
#   as a safety net.

runtimes/
