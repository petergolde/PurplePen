# publish-exclude.txt
#
# Files and directories to leave OUT of the Linux packages.
#
# This is passed to rsync as --exclude-from when copying the dotnet publish
# output into the payload staging directory, so it uses rsync's filter syntax:
#
#   Foo.dll             matches Foo.dll at any depth
#   /Foo.dll            matches Foo.dll only at the top level of the publish dir
#   *.pdb               glob, matches at any depth
#   sv/                 trailing slash matches directories only
#   **/Bar              ** crosses directory boundaries
#
# Blank lines and lines starting with # are ignored.
#
# Anything excluded here is simply absent from the package -- there is no error
# if the app later tries to load it, so re-test the built package after each
# change.
#
# ---------------------------------------------------------------------------
# --- runtimes/ for other platforms ----------------------------------------
#
#   AvPurplePen.csproj used to copy PdfConverter's entire build output into
#   the publish directory, including its RID-agnostic runtimes/ folder of
#   native pdfium and libSkiaSharp binaries for every platform (about 399 MB;
#   excluding it took the payload from roughly 721 MB to 145 MB). PdfConverter
#   is now a plain library, and a self-contained RID-specific publish flattens
#   the native libraries it actually needs (libSkiaSharp.so, libpdfium.so and
#   friends) into the top level of the payload, so the tree should no longer
#   appear at all.
#
#   Nothing would load it if it did: PurplePen.deps.json contains no
#   runtimeTargets entry, and runtimeTargets is the only mechanism by which the
#   host probes runtimes/<rid>/native/. The exclusion stays as a safety net.

runtimes/

# --- Other platforms' build output: handled automatically, do not list -----
#
#   A top-level directory named after another runtime identifier (win-x64/,
#   osx-arm64/, ...) would hold binaries this package can never load.
#
#   These are NOT listed here. build-linux-packages.sh detects them by name at
#   staging time and excludes them, so a RID nobody has thought of yet is
#   caught without this file needing an edit. It logs each one it skips.
#
# --- .NET Framework configuration files -----------------------------------
#
#   Nothing on .NET 10 reads a .dll.config. Kept as a safety net; these used
#   to arrive with PdfConverter's build output.

*.dll.config

# --- Debug symbols --------------------------------------------------------
#
#   Safe to drop; only affects the quality of crash stack traces. DebugType is
#   already set to none for the main publish, so this only catches stragglers.

*.pdb
